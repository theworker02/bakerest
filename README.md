# bakerest

Bake URLs and rest query parts with stable normalization.

**Site:** https://theworker02.github.io/bakerest/

## Install / run

```bash
git clone https://github.com/theworker02/bakerest.git
cd bakerest
node src/cli.js
node --test
```
